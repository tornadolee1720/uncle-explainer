# 示例：《AI到底有多燒錢》（第六版，77 秒）

這是一條影片從想法到成片的記錄，用來學“怎麼想”。**不要照著它的鏡頭順序做新片。** 新片的畫面要從新片的文案裡現想。

- `script.txt`：最終文案。原聲部分不在裡面，見下表“反應梗”和“扎克伯格”兩行。
- `director.md`：第五版的導演表。注意每一鏡的“承接”一列：它接住了上一鏡的什麼。第六版文案和鏡頭分段沒變，改的是每一鏡怎麼動，見下表。
- `sample.gif`：第六版整片壓成的 GIF（360 寬、6 幀/秒，沒有聲音）。
- `frames_1fps.jpg`：第六版每秒一幀。
- `moves_v6.jpg`：第六版四個動作的連續幀：
  - 鏡頭沿新聞桌面滑過去；
  - 黃仁勳從實拍原位挪進巨字中間；
  - 橫推換人；
  - 原文倒成桌面、圖表立起來。
- `v5b_vs_v6.jpg`：同一時刻，第五版 b 和第六版並排。
- `film_lib.js`：第六版的畫面程式碼，用底座 `film_base.js` 和手法庫 `moves.js` 寫成，和原版逐幀一致。14 鏡裡 10 鏡用了手法、4 鏡全手寫，每處手法都寫了 why。素材不隨倉庫給，這份程式碼只用來讀：看手法怎麼嵌在手寫的畫面裡，不要照抄鏡頭。
- `moves_lib.json`：對它跑 `render.mjs --moves` 的結果（每鏡用了哪些手法），新片可以用 `--prev` 和它比，免得照著排。
- `CREDITS.md`：全部素材的出處（實拍、摳像、新聞截圖、照片、音效）。

## 論證主線

追一筆錢：
1. 四家一年砸 7250 億；
2. 大頭流向晶片和資料中心；
3. 賣晶片的英偉達成了全球市值第一；買算力的 OpenAI 估值高但收入小，到 2030 年還要虧 2780 億；
4. OpenAI 的錢有一筆來自英偉達，錢在英偉達、OpenAI、甲骨文之間轉了一圈；
5. 一年砸進去 7250 億，收回來的差一大截；
6. 這一截就是賭注，連押注的人自己都知道可能白花。

## 每一段怎麼動、為什麼（第六版）

| 段 | 畫面和鏡頭 | 為什麼 |
|---|---|---|
| 開頭 | “燒錢”快閃：關鍵詞釘在中央，周圍的出處每 5 幀換一張；最後一張衝過鏡頭 | 觀眾的視線有落點，一眼看出“全網都在說”；墊在第一句話下面，不空等 |
| 四家 | 四家的資本開支新聞平鋪在一張透視桌面上，唸到哪家，鏡頭沿桌面滑到哪張，唸到才亮；“這四家”抬高看全 | 東西早就在，鏡頭去找它；標題裡寫著公司名和金額，身份自己說清 |
| 加起來 | 桌面放平、壓暗、退成底；7250 億立在上面，從第一家的 1800 億滾到 7250 億（滿位數、按十億取整），說到“七千多億”停 | “加起來”本身就是累加，滾數在這裡是內容，不是裝飾 |
| 片名 | 數出來的 7250 億縮成片名上的眉題；底下的資料中心實拍壓暗去色，0.42 秒換一座 | 釘住一個東西、底下換實拍：錢 = 這些樓 |
| 錢花哪了 | 片名退開，7250 億回到中間當錨，底下還在換實拍；“晶片”“資料中心”兩個畫框一左一右甩進來，錢的線分過去 | 一個數分成兩路；兩樣東西同時停在畫面上 |
| 英偉達 | 晶片畫框推滿屏 → 黃仁勳臺上的實拍 →“市值”那一幀他身後的臺換成英偉達的綠，“5.2 | 萬億”在他頭兩側長出來，他從原位挪到畫面中間 →“全世界最值錢”他正好張開雙手，字翻成“全球 | 第一” | 人站在巨字前面：這個人 = 這個數；原片裡的動作對上臺詞 |
| OpenAI | 整組連字帶人往左橫推走（運動模糊），Altman 帶著青色的底推進來；“八千五百二十億”立在他身後；“收入”時肩旁冒出一張小卡“$360 億”，身後的大字虛掉 | 橫推 = 換一個人說；大字和小卡同框，“才 360 億”一眼可見 |
| 淨燒 | 路透原文整頁 → 推近刷黃 →“它還準備”整頁往後倒成桌面壓暗，白底圖表立起來，累計淨燒跟著曲線滾到 2780 億 | 可能被質疑的數先給出處；按年累計是真的累加 |
| 算力 | 圖表縮到左邊，它身後的桌面換成星門工地的實拍（壓暗），8560 億立在右邊 | 底下換成實拍：錢 = 這片工地；兩個數並排，不用說出來 |
| 資金迴圈 | 工地實拍虛掉退成桌面；鏡頭在 OpenAI 上慢漂 →“英偉達”搖過去找到它 → 錢流到哪跟到哪（CNBC 新聞小卡從“投資”箭頭旁彈出又縮回）→“轉了一圈”拉回看全、亮點跑一圈 →“回到英偉達手裡”推過去、其餘壓暗 | 同一個世界裡換機位，鏡頭的落點就是正在說的那一家 |
| 反應梗 | “難怪黃仁勳總愛說這句：”→ 從他的圓盤撐開小窗：“買得越多，省得越多” | 先鋪墊再放；從盤裡撐開，觀眾知道這是誰 |
| 差一大截 | 回到片名那串實拍上問“AI到底有多燒錢？”→ 低機位的地面上紅柱長到 7250 億 → 搖到矮柱打問號 → 鏡頭沿著差的那一段往上抬，括號跟著畫出來 | 開頭的數和片名都回來了；鏡頭的移動本身在說“差得多” |
| 賭 | 差額那一段亮起；四家的籌碼沿地面推上去；“能不能”鏡頭推到問號 | 首尾呼應：押注的就是開頭那四家 |
| 扎克伯格 | “連扎克伯格自己都說：”鏡頭推到 Meta 那枚籌碼 → 推過鏡頭到他本人，三句原聲 | 結尾回到一個判斷：他們知道可能白花，還是要砸 |

量出來（`motion_check.py`）：畫面完全不動的時間 20%（參考片 15–29%，第五版 b 66%），定住超過 2 秒 0 次，鏡頭在動的時間 24%（參考片 21–27%）。

## 摔過的跤

| 版本 | 問題 | 改法 |
|---|---|---|
| v1 | 全片 PPT 感：AI 生成的寫實背景當牆紙；圓盤一個個彈出來排隊、重排；每個數都滾；整張平面一起慢慢往外拉 | 當時把動畫全砍成淡入和硬切。回頭看：該砍的是元素自己演、每個數都滾、AI 牆紙，不是動本身 |
| v2 | 清楚的實拍上壓字 | 當時改成實拍上一律不壓字。後來改成只留兩種壓法：人站在巨字前面、實拍退成底 |
| v3 | 低清百科素材；平面慢推；開頭的冷卻管道沒有資訊量 | 換官方高畫質素材；當時把慢推全刪了（後來證明刪過頭） |
