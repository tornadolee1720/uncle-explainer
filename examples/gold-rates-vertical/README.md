# 例子：《打仗黃金反而跌》直式版（28.8 秒，1080×1920）

橫式例子 `examples/gold-rates/` 的同一條口播，裁進直式重新包裝。口播是 16:9 拍的，沒有重拍。

- 12 鏡，用了 9 種直式場景：`v-host` `v-host-bubbles` `v-clip`（兩次）`v-line` `v-host-num` `v-title` `v-chain` `v-doc`（兩次）`v-host-cards` `v-host-words`
- 排法：她開口 → 氣泡立靶子 → 實拍 → 走勢線 → 大數拍胸前 → 整屏大字給答案 → 因果鏈 → 原文截圖 → 回到她出兩張卡 → 實拍 → 原文截圖 → 回到她收尾
- `film.js` 就是成片用的鏡頭表，可以直接對著抄寫法；`script.json` 是文案，`sfx.json` 是聲音表

這個資料夾只放寫法，不帶素材（口播幀、新聞截圖、實拍）。要跑起來：`node scripts/new_film.mjs <目錄> --vertical` 建工程，把這裡的 `film.js`、`script.json` 拷進去，素材按 `film.js` 裡的路徑補上。

幾處值得看的寫法：
- 第 5 鏡 `v-host-num`：數字預設拍在她胸前。別放身後（`behind:true`），短數字會被頭擋得只剩符號。
- 第 3、10 鏡 `v-clip` 的 `tags`：寫的是字幕裡沒有的資訊（油價、地名），不是把字幕再抄一遍。
- 第 8、11 鏡 `v-doc`：截圖先裁到只剩標題那一段，再量熒光筆的位置。
- 第 12 鏡 `zoom` 寫成陣列：說到後半句硬切近一檔，結尾不用另加動效也有力氣。
- 第 6 鏡 `v-title` 的 `pic`、第 7 鏡 `v-chain` 每環的 `img`：這四張是生圖做的（金色百分號雕塑；油桶、購物車、央行大樓的白底插畫）。怎麼要圖見 `kit/VERTICAL.md` 的"質感靠圖"。
