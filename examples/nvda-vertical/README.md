# 樣片：《英偉達拒絕老黃迴歸》直式真人口播（28.7 秒，8 鏡）

這是 vpro 精裝元件（`kit/vpro.js`）的樣片：使用者看到第九版說"行"的那一版，2026-11-20。

**樣片是品質的底，不是模板。** 下一支片要做到這個水平，但每一鏡要有自己的演法：換道具、換詞、換哪一鏡最重。照著這份鏡頭表換字，出來的是第二條一模一樣的影片。

## 這支片是怎麼定下來的

口播是使用者給的直式影片，原話一字不改。前八版被打回的原因，按出現順序：

1. 證據全是白卡，平，像 PPT → 換成有厚度、有前後層的東西。
2. 八鏡都是同一種"砸下來"，重複 → 八鏡八種進場。
3. 只有字和卡，沒有會演的東西 → 加道具，演口播裡的詞（反轉、潑冷水、拍板、印鈔機）。
4. 漫畫氣泡、紅章、警戒帶、熒光綠混在一起，怪 → 全片一套顏色、一種卡。
5. 金字棕邊、程式碼畫的道具、到處在晃，廉價 → 顏色取自她的紫灰開衫；道具換真照片摳圖和生圖；落定後不動。

第 5 條是把參考片（小Lin說）和自己的同類鏡頭放大並排看才看出來的。所以開工第一步是並排對照，見 `SKILL.md`。

## 沒驗證過的

- 音效（26 個點，Freesound 真錄）沒有人聽過。
- 進場的連續動作只逐幀看過法槌、水桶、新聞卡三處。
