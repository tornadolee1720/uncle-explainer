# vpro 圖形元件樣張

`film.js` 一鏡放一個元件，一共 12 個（提問、柱子、對比、因果鏈、要點、走勢線、圖窗、引語、時間線、佔比、排行、分段），沒有口播。`gallery12.jpg` 是每鏡落定的一幀。

想自己跑：`node scripts/new_film.mjs <目錄> --vertical`，把這裡的 `film.js` 拷過去，圖換成自己的，`render.mjs --dir <目錄> --sheet`。

裡面的數來自英偉達和黃金兩條樣片；標了"示意"的兩鏡（走勢線、排行）是編來看版式的，不是真資料。照片出處見 `../nvda-vertical/README.md`。
