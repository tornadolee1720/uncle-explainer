# 直式版（9:16）：29 個場景，照著填就能出片

直式版給手機看：1080×1920，學自小Lin說在IG發的三條直式片（汽車、太空旅遊、免稅）。
和橫式版是兩套場景：直式的場景名都以 `v-` 開頭，橫式的場景（`host`、`person`、`ledger` 這些）不要拿到直式裡用。

這份文件是照著填用的。**不用自己設計畫面**：一句話在說什麼，就去下面的表裡找對應的場景，把這一句的內容填進去。位置、字號、顏色、進場都是場景自己管的。

## 精裝元件 vpro（v2.6 起，新片預設用這一套）

二十個 `vp-` 開頭的元件，寫在 `kit/vpro.js`、`kit/vpro.css`，`new_film.mjs --vertical` 起步時已經帶上。它們是《英偉達拒絕老黃迴歸》直式改到第九版、使用者點頭的那套畫面拆出來的，樣片在 `examples/nvda-vertical/`。
**樣片是品質的底，不是模板**：下一支片每一鏡要有自己的演法（換道具、換詞、換哪一鏡最重），不能照著樣片換字。

**三步用上**

1. 定強調色：`python scripts/pick_accent.py <她的一幀 或 主圖>`，它會報畫面裡最大的幾堆顏色和各自能用的強調色，挑和主體最貼的那個（膚色、木頭色它會標出來，不選）。在 `film.js` 的 `KIT_VERT.use(…)` 後面寫一句 `KIT_VPRO.theme({accent:'#8a86ee', bg:'assets/img/主圖.jpg'})`，卡的底色、細邊、數字、立體字的顏色都跟著它變；`bg` 是沒有她的鏡頭預設墊的圖。
2. 每一鏡先在導演表裡寫清"觀眾要懂什麼、畫面上有什麼、怎麼進來、演哪個詞"，再從下表選元件。挑一兩個口播裡的詞做成道具（見下面"道具"）。
3. `render.mjs --check` 改到沒有提醒，再渲單幀拼聯絡表，和參考片並排看。

**兩種模式，同一份鏡頭表**

| | 有真人口播 | 沒有人出鏡 |
|---|---|---|
| 聲音和時間線 | 口播原片，`host_timeline.py` 逐字對齊 | 配音：每句存成 `voice/<id>.final.wav`，`temp_voice.py script.json` 對齊（設環境變數 `WHISPER_MODEL=<本機模型資料夾>`，不然會連網等很久） |
| `KIT_VERT.use` | 寫 `host:{name:'host',fps:30,…}` | 不寫 `host` |
| 元件墊什麼 | 她的實拍；證據鏡頭角上有她的圓頭像 | `bg`（這一鏡寫的，或 `theme` 裡那張；沒寫 `bgpos` 時每鏡自動換一個裁法） |
| 景別 `zoom` | 在重音的詞上硬切一檔 | 不用寫 |
| `vp-number` 的巨數 | 有摳像時在她身後；牆暗用亮色、牆亮用深色，自己量 | 亮色，整個露出來 |
| 要多想一步的 | 相鄰兩個她的鏡頭景別差 0.15 以上 | 她不在，主角得是東西：第 1 鏡把道具做大放中間，`vp-words` 用 `y` 把詞挪到上面 |

兩種都驗證過：`examples/nvda-vertical/film.js`（有口播）和 `film_nohost.js`（無人）是同一支片；`examples/gold-rates-vertical/film_vpro.js` 是換了一個題目、換了一位口播，只用 skill 裡的東西做的。

**元件表**（引數的完整說明在 `vpro.js` 每個元件的 `help` 裡，寫錯引數名 `--check` 會報錯）

| 元件 | 這一鏡在說什麼 | 必填 | 常用 |
|---|---|---|---|
| `vp-words` | 一兩個要記住的詞，卡著她說的字出現 | `words` | `en` 英文小字、`zoom` 在重音上切景別、`fx:'flip'` 整行翻一下 |
| `vp-newspile` | 這事到處在報：新聞卡飛下去摞成一摞 | `items` | `bg` 墊底的圖、`brow`、`stamp` 最後蓋一塊牌 |
| `vp-person` | 當事人自己說了什麼：摳像站前面，原話打字，巨字從身後滑出 | `cut`、`lines` | `quote`、`name`、`cardOut`、`source` |
| `vp-reject` | 轉折、被拒：一個詞砸下，下一個詞從頭頂掉下來 | `stamp` | `drop`、配一個 `pour` 道具 |
| `vp-paper` | 原文為證：帶報頭的紙轉正，推到那一行刷黃 | `img` | `mast`、`hl`、`tag` 誰說的 |
| `vp-verdict` | 全片的結論，最重的一鏡，只用一次 | `lines` | `cut` 當事人、`note` 原話卡、`hero:true` |
| `vp-voices` | 幾個人表態，然後被一句話壓下去 | `items` | `deny`、`bar` |
| `vp-number` | 用一個數收尾 | `value` | `unit`、`label`、`pct`；有口播摳像時數字真的在她身後 |
| `vp-ask` | 把問題拋給觀眾：巨大的問號壓在後面 | `lines` | `at`、`zoom` |
| `vp-bars` | 幾個數比大小：柱子往上長 | `items` | `unit`、`title`；`hl:true` 的那根是強調色 |
| `vp-versus` | 兩樣東西對著看 | `left`、`right` | `win` 讓一邊贏 |
| `vp-chain` | 因果鏈：一環扣一環 | `items` | 每環 `value`、`sub`、`img` |
| `vp-list` | 幾條要點一條條翻出來 | `items` | `mark:'ok'/'no'`、`hl` |
| `vp-line` | 走勢線從左畫到右 | `data` | `marks`、`drawTo`、`down`、`source`（要寫） |
| `vp-photo` | 一張圖當主角：大窗轉進來 | `img` | `tags`、`source` |
| `vp-quote` | 一句引語（沒有摳像時用） | `lines`、`name` | `tag`、`img` 頭像 |
| `vp-timeline` | 幾個有日期的節點 | `items` | 每個 `date`、`text`、`hl` |
| `vp-share` | 一個佔比：圓環畫到那個百分比 | `value` | `label`、`note` |
| `vp-rank` | 有名次的比較：橫條排行 | `items` | `hl` |
| `vp-chapter` | 分段的小標題（長片用） | `title` | `no`、`en` |

前 8 個加 `vp-ask` 是"講故事"的：有口播時她是底。其餘 11 個是"圖形鏡頭"：有口播時她在右上角的圓頭像裡。圖形鏡頭的內容放在一張有透視的斜檯面上，卡有厚度、柱子是長方體、強調的那一項浮起來一層（某一鏡想平著放寫 `flat:true`）。樣張：`examples/vpro-gallery/`。

**道具**：任何元件都能寫 `props:[{kind, img, at, …}]`，一鏡最多一樣，演口播裡的一個詞。

| kind | 演什麼 | 圖要什麼樣 |
|---|---|---|
| `obj` | 一樣東西從邊上滑進來停住（晶片、產品、車） | 摳好的透明 PNG |
| `pour` | 從右上伸進來，下半截從上往下露出來（倒水、撒東西） | 東西在右上、流下來的部分在左下 |
| `hammer` | 舉起、砸在底座上、收走（拍板、敲定） | 槌頭在左、柄朝右的橫圖；`block` 是底座 |
| `bills` | 一張張噴上來在空中翻（鈔票、傳單） | 一張平的圖；`layer:'behind'` 放她身後，`big:true` 是鏡頭前虛的幾張 |

圖從哪來：真照片（Wikimedia Commons 的 CC0、公有領域）用 `scripts/cut_img.py` 摳；找不到就用 `scripts/gen_prop.sh` 生圖（三維小道具、淺灰平底；第 4 個引數寫這支片的顏色），再摳。出處記進 `assets/img/credits.json`。

**規矩**

| | 規矩 | 為什麼 |
|---|---|---|
| 硬 | 畫面上的原話、數字、人名都要核過出處 | 截圖和引語是證據 |
| 硬 | 引數名、`props` 的 `kind` 寫錯會報錯，不會悄悄丟掉 | 看不了圖的模型發現不了畫面少了東西 |
| 預設 | 顏色一個家族：一個主色（取自口播畫面，管卡的底、細邊、大字）加三個伴色（按主色自動配的青綠、杏橙、天藍，飽和度壓得低；一屏只有被強調的那一樣是全色，其餘灰一檔），圖形鏡頭裡每樣東西輪著用；自己做的卡只有一種（深色玻璃卡加淺色細邊），白紙只留給真截圖 | 參考片每條有一個主色，但柱子、徽章、表格行各有各的顏色，不是一屏一個色；混進別的風格（漫畫描邊、警戒條、金字棕邊、熒光色）才會打架 |
| 預設 | 口播畫面保持亮，不壓黑漸變；東西做大、敢出框 | 參考片的口播是亮的，字直接壓在亮畫面上 |
| 預設 | 每個元件一支片用一兩次，相鄰兩鏡進場不重複 | 同一種砸法連著用，看著像套模板 |
| 預設 | 落定後不動：不彈、不晃、不飄、鏡頭不頓、口播不慢推 | 參考片量過，停住以後一個畫素不動 |
| 預設 | 道具用真東西的摳圖或生圖，不用程式碼畫 | 程式碼畫的桶和槌像剪貼畫 |

偏離"預設"可以，在導演表裡寫一行為什麼。

**舊場景**：下面文件裡的 `v-` 場景是上一代的畫法，新片優先用 `vp-`：`v-host-words`→`vp-words`、`v-stack`→`vp-newspile`、`v-doc`→`vp-paper`、`v-title`→`vp-verdict` / `vp-ask`、`v-host-sides`→`vp-voices`、`v-host-num` / `v-number`→`vp-number`、`v-bars`→`vp-bars`、`v-vs`→`vp-versus`、`v-chain`→`vp-chain`、`v-list`→`vp-list`、`v-line`→`vp-line`、`v-quote`→`vp-quote`、`v-pie`→`vp-share`、`v-chapter`→`vp-chapter`、放圖的 `v-full`→`vp-photo`。`vp-` 裡沒有的（實拍片段 `v-clip`、表格 `v-table`、手機截圖 `v-phone` 這些）照舊用 `v-`，可以混在一支片裡。

**檢查全綠不等於影片好**：渲完用 `scripts/sheet.py` 把每鏡的落定幀拼成聯絡表，和參考片的同類鏡頭放大並排看，寫出差距再改（看亮度、顏色、大小、道具真假、落定後動不動）。

## 一屏長什麼樣

```
┌──────────────┐ 0
│              │
│   畫面區      │  上面 82%（0–1574）：她在講 / 素材 / 卡片 / 圖表 / 大字
│              │
│  （字幕壓在   │  字幕在 69%–73% 高，壓在畫面區下沿
│   這一帶）    │
├──────────────┤ 1574  接縫正中是欄目小標（brand）
│   黑條        │  下面 18%：留給平臺的標題、點贊按鈕，不放東西
└──────────────┘ 1920
```

- 鏡頭之間只有硬切，不寫 `enter`。
- 一鏡只講一件事。東西一句出一樣（`items` 裡每個寫 `at:'@b03:詞'`），出來了就留著，不閃走。
- 一鏡 1.5–5 秒。她連續露臉超過 8 秒，要換景別（`zoom`）或者出東西。
- 證據鏡（`v-clip` `v-doc` 這些）之後回到她，再去下一段證據。沒有口播時，用 `v-title`、`v-number` 當"喘氣"的地方。

## 五步出片

```
node scripts/new_film.mjs <影片目錄> --vertical      # 建工程（想先看全部場景長什麼樣：--demo-v）
（寫 script.json：一句一個 id，一個分句不超過 14 個字）
（時間線：有口播用 host_timeline.py，沒有用 temp_voice.py 或 timeline_stub.mjs，和橫式版一樣）
（寫導演表，再寫 film.js：每鏡從下面的表裡選場景）
node scripts/render.mjs --dir <影片目錄> --check      # 查表：填錯的引數、太短的鏡頭、放不下的字，都會用大白話告訴你怎麼改
node scripts/render.mjs --dir <影片目錄> --sheet      # 出聯絡表，看每一鏡
node scripts/render.mjs --dir <影片目錄> --video --h 1080 --workers 2    # 成片畫面 1080×1920（預覽用 --h 720）
python scripts/mix.py <影片目錄> --check              # 混音，和橫式版一樣
```

`--h` 寫的是短邊：直式 `--h 1080` 出來是 1080×1920。

## film.js 開頭怎麼寫

```js
const K=await KIT.use(F);
await KIT_VERT.use(K,{
 skin:'dark',      // 'dark' 黑底圖示底紋 + 白紙卡 + 立體厚字（財經、科技）/ 'paper' 灰紫底 + 米白卡 + 綠重點（生活、消費）
 pattern:'gold',   // 黑底上平鋪的線條小圖示，挑和題目沾邊的：chart 走勢 / gold 金條 / coin 錢 / oil 油桶 / car 車 / rocket 火箭 / bag 購物袋
 brand:'橙C',      // 接縫上的欄目小標，不要就寫 ''
 host:{name:'host',fps:30,faceY:330,bright:1.15},   // 有口播才寫，見下面"有口播"
});
await K.film([ /* 一鏡一個物件 */ ]);
```

每一鏡三樣必寫：`scene`（場景名）、`until`（到哪一刻結束，最後一鏡不寫）、`says`（這一鏡讓觀眾多懂了什麼）。
時刻一律寫 `'@句id'` 或 `'@句id:詞'`（唸到這個詞的那一刻），不寫秒數。

## 有口播

- 口播是橫式拍的也行：場景會自動把她裁進直式的畫面區，臉放在畫面 31% 高。
- 口播按原片幀率抽幀到 `assets/clips/host/0001.jpg…`（1920×1080），`assets/clips/counts.json` 裡登記 `"host": 幀數`。
- `host:{name, fps, faceY, bright}`：`fps` 是口播原片的幀率；`faceY` 是她臉中心在原片（1080 高）裡離上沿多少畫素，拿一幀量一下；`bright` 是提亮倍數，室內拍的臉發暗就寫 1.1–1.2。
- 有口播時，卡片類場景（第三組全部、`v-doc`）右上角會自動帶她的圓頭像，不想要就在那一鏡寫 `avatar:false`。
- 橫式口播裁進直式以後，景別 1.0 已經是最遠，人還是比豎著拍的近。想要半身中景，只能豎著重拍。
- 她站得偏左或偏右：在 `zoom` 裡寫 `x`（`zoom:[{at:'@b01',s:1.15,x:-.2}]`）。
- 摳像（`assets/cut/host/`）不是必須的。只有 `v-host-num` 寫了 `behind:true` 才用得到。
- 口播拍得太滿（頭頂貼邊）時，`zoom` 別超過 1.2，不然頭髮會被裁掉。

## 沒有口播

六個 `v-host` 開頭的場景不能用，其餘 23 個照常。對應換法：

| 有口播時 | 沒口播時換成 |
|---|---|
| `v-host`（她說觀點） | `v-title`（整屏大字） |
| `v-host-num` | `v-number` |
| `v-host-words` | `v-title` |
| `v-host-cards` | `v-list` / `v-data` / `v-vs` |
| `v-host-bubbles` | `v-stack`（沒截圖就寫 title）/ `v-quote` |
| `v-host-sides` | `v-collage` / `v-brand` |

`v-clip` 的圓頭像會自動不出。

## 先當導演，再填表

模板管的是"每一鏡長什麼樣"。一支片好不好看，先看下面五件事定沒定。填表之前用五行字寫下來（寫在 shots.md 開頭），定不下來就先別填。

| 先定什麼 | 怎麼定 | 寫錯了會怎樣 |
|---|---|---|
| 一句話 | 觀眾看完能轉述給別人的那一句（"利率高了，黃金就吃虧"）。每一鏡都要為它出力 | 每鏡都對，連起來不知道在講什麼 |
| 最重的一鏡 | 全片只有一個：答案出現的那一鏡，或最大的那個數。給它 `hero:true`（進場多一下白閃和衝鏡）、最大的字、一張專門生的圖 | 鏡鏡都使勁，觀眾一個也記不住 |
| 輕重三檔 | 重：整屏立體字、胸前大數（全片 2–3 次）。中：白紙卡、截圖、實拍帶。輕：她 + 一個標籤 | 一路都是"中"，看著像幻燈片 |
| 呼吸 | 她說觀點 → 最多 3 鏡證據 → 回到她。連著兩鏡都是她，景別換一檔。重的一鏡前面放一鏡輕的 | 證據連著轟，觀眾忘了誰在講；或者她一直講，沒東西看 |
| 哪幾處要圖 | 因果鏈的每一環、整屏標題的窗、證據截圖。先列出來去生圖 / 截圖，再填表 | 白板上只有色塊，質感掉一檔 |

`--check` 會替你查其中能數的幾項：有沒有標最重的一鏡（多於一個也報）、她露臉佔三成到六成、證據有沒有連著超過 3 鏡、連著兩鏡景別一樣、因果鏈和整屏標題有沒有圖。查不了的是"一句話"和"輕重"，這兩樣要自己想。

這個 skill 用到頭是這樣：拿到一條口播，先找出那一句話和最重的一鏡，其餘的鏡頭都是給它們鋪路。模板只是把鋪路的活變成填表。

## 這句話在說什麼 → 用哪個場景

先看左邊一列找到這句話的意思，再用右邊的場景。找不到完全對的，就用最近的；實在沒有，用 `v-clip`（有畫面）或 `v-list`（沒畫面）。

### 一、她在講（要有口播）

| 這句話在說什麼 | 場景 | 什麼時候用 | 別這麼用 | 最短 |
|---|---|---|---|---|
| 她對著鏡頭講：開頭打招呼、拋問題、說觀點、結尾收話 | `v-host` | 沒有別的東西要給觀眾看的句子；每段證據之後回到她 | 一口氣超過 8 秒不換景別、不出東西 | — |
| 她一邊講，胸前一張一張出卡片：幾個選項、幾家公司、幾個要點 | `v-host-cards` | 並列的 2–3 樣東西，她唸到哪個出哪個 | 超過 3 張（改 v-list）；卡上寫長句 | 1.6 秒 |
| 她說出一個大數，數字拍在她胸前 | `v-host-num` | 這句話的主角是一個數：漲了多少、虧了多少、多少錢 | 一句裡兩個數（改 v-data） | 1.2 秒 |
| 她說到關鍵詞，大字一個一個拍在她胸前 | `v-host-words` | 一句話裡有 1–3 個要觀眾記住的詞；反問、口頭禪、結論 | 整句話都打出來（那是字幕的事） | 1.2 秒 |
| 她轉述別人的話、網友的問題：氣泡在她頭兩邊冒出來 | `v-host-bubbles` | "有人說……""你可能會問……"；幾種常見說法 | 氣泡裡寫超過 14 個字 | 1.5 秒 |
| 她提到的人 / 公司，照片卡立在她兩邊 | `v-host-sides` | 講到一兩個當事人、兩家對手 | 沒有照片（改 v-host-cards） | 1.5 秒 |

### 二、把證據擺出來

|---|---|---|---|---|
| 實拍 / 照片放在中間一條寬頻裡，上面一行標題，帶子上疊標籤、數字、人 | `v-clip` | 這句話有現成的畫面可看：新聞現場、產品、當事人、地方 | 素材和這句話沒關係（只為了不空著） | 1.2 秒 |

### 三、算賬、比較、講道理

| 這句話在說什麼 | 場景 | 什麼時候用 | 別這麼用 | 最短 |
|---|---|---|---|---|
| 一張清單卡：幾條原因 / 幾個選項 / 幾步，念一條出一條；最後可以落一塊答案 | `v-list` | "有三個原因""要看這幾樣"；排除法（前幾條打叉，最後一條是答案） | 超過 5 條；每條超過 14 個字 | 1.5 秒 |
| 幾行"名字 + 數字"：左邊是什麼，右邊是多少 | `v-data` | 一句話裡報了 2–4 個數；幾個指標並排看 | 只有一個數（v-number / v-host-num）；要比大小（v-bars） | 1.5 秒 |
| 橫條比大小：誰多誰少一眼看出來 | `v-bars` | 幾樣東西比同一個數（銷量、價格、佔比） | 數字差不多大（比不出來）；超過 6 條 | 1.8 秒 |
| 上下兩塊對著比：A 是這樣，B 是那樣 | `v-vs` | 兩種選擇、兩家公司、以前和現在 | 三樣以上（v-table） | 2 秒 |
| 一個圓環分成幾塊：錢 / 人 / 份額是怎麼分的 | `v-pie` | 佔比、構成（加起來是 100%） | 超過 5 塊；不是"構成"的數 | 1.8 秒 |
| 一個數原地變成另一個數：從多少到多少 | `v-move` | 漲了、跌了、砍半、翻倍：變化本身是這句話的意思 | 只有一個數（v-number） | 1.5 秒 |
| 一筆一筆加起來，底下落一個總數 | `v-sum` | 算賬：幾項成本、幾筆收入加起來是多少 | 不是加法關係的幾個數（v-data） | 2 秒 |
| 一張對比表：幾樣東西按幾個方面比，一行一行出 | `v-table` | 三樣以上的東西橫著比；片尾的總結表 | 超過 4 列、6 行；格子裡寫句子 | 2 秒 |
| 一條走勢線從左畫到右：漲上去、掉下來，關鍵的點標出來 | `v-line` | 價格、利率、銷量隨時間的變化 | 只有兩三個點（v-move） | 2 秒 |
| 因果鏈從上往下一環扣一環：因為 A，所以 B，所以 C | `v-chain` | 解釋"為什麼"：一步一步推過去 | 並列關係（v-list）；超過 4 環 | 2 秒 |

### 四、整屏大字、提問、品牌、引語

| 這句話在說什麼 | 場景 | 什麼時候用 | 別這麼用 | 最短 |
|---|---|---|---|---|
| 整屏斜體大字：片名、一句核心問題、一句結論 | `v-title` | 開頭拋問題；中間夾在兩段證據之間的一句答案；全片最多三次 | 一行超過 7 個字；連著用 | 1 秒 |
| 一道選擇題：先給選項讓觀眾猜，再亮答案 | `v-quiz` | 開頭勾人："你猜是哪個？"；反常識的事實 | 答案顯而易見；一支片超過一次 | 2 秒 |
| 一牆色塊：幾家公司 / 幾個品牌 / 幾個國家，說到誰亮誰 | `v-brand` | "這個行業有這幾家"；點名 | 超過 6 個；要比數字（v-bars） | 1.5 秒 |
| 一句引語：誰說的，原話是什麼 | `v-quote` | 當事人、官方、報告裡的一句關鍵原話 | 轉述（直接讓她說）；超過 30 個字 | 1.8 秒 |
| 整屏只有一個大數 | `v-number` | 全片最重要的那個數；沒有口播素材時代替 v-host-num | 一支片超過兩次 | 1.2 秒 |

## 每個場景怎麼填

每個場景一段：必填項、全部引數、一行能直接抄的例子。例子裡的 `scene` `until` `says` 每一鏡都要寫，後面不再重複說明。

### 一、她在講（要有口播）

#### v-host

她對著鏡頭講：開頭打招呼、拋問題、說觀點、結尾收話。

| 引數 | 寫什麼 |
|---|---|
| `zoom` | 景別：1.25 這樣的數字，或 [{at:'@b02',s:1.3,x:0}] 中途硬切換檔 |
| `name` | 名字條（第一次出場寫一次） |
| `role` | 名字條第二行：身份 |
| `nameAt` | 名字條出現的時刻 |
| `caption` | 她頭頂的一行小標題 |

```js
{scene:'v-host', until:'@b02', says:'先認識她，知道今天聊什麼', zoom:1.15, name:'橙C', role:'今天聊黃金', nameAt:'@b01:最'},
```

#### v-host-cards

她一邊講，胸前一張一張出卡片：幾個選項、幾家公司、幾個要點。

必填：`items`

| 引數 | 寫什麼 |
|---|---|
| `items` | [{title, sub, img, value, color, at:'@b03:詞'}]，最多 3 張（bar 最多 4 條） |
| `shape` | 'row' 半透明矮卡一排，title 是卡頂的小標籤、value 是卡里的大字（預設）/ 'tall' 豎高卡（帶圖）/ 'bar' 橫條一條一條往下摞 |
| `title` | 頭頂一行小標題 |
| `zoom` | 景別，同 v-host |

```js
{scene:'v-host-cards', until:'@b10', says:'黃金沒利息，美債有', items:[{title:'黃金', value:'0%', sub:'不生利息', color:'gold', at:'@b08'},{title:'美債', value:'4.9%', sub:'每年穩拿', color:'green', at:'@b09'}]},
```

#### v-host-num

她說出一個大數，數字拍在她胸前。

必填：`value`

| 引數 | 寫什麼 |
|---|---|
| `value` | '6.9%' '$104' '3.6億' |
| `label` | 數字下面一行說明 |
| `at` | 數字出現的時刻 |
| `color` | 'red' / 'green'，預設金色 |
| `roll` | true = 從 0 滾到這個數 |
| `behind` | true = 數字放到她身後（要摳像；數字中間會被頭擋住，只適合 5 位以上的長數） |
| `zoom` | 景別，同 v-host |

```js

```

#### v-host-words

她說到關鍵詞，大字一個一個拍在她胸前。

必填：`words`

| 引數 | 寫什麼 |
|---|---|
| `words` | [{text:'反而跌', at:'@b03:反而', hl:true}]，最多 3 個，每個不超過 6 個字；hl:true 的那個更大、金色；中文詞會逐字錯開一點大小和角度 |

```js
{scene:'v-host-words', says:'記住一個動作：先看利率', words:[{text:'先看一眼', at:'@b11:先'},{text:'利率', at:'@b11:利', hl:true}]},
```

必填：`items`

| 引數 | 寫什麼 |
|---|---|
| `items` | [{text:'亂世買黃金', mark:'？', at:'@b02:亂世'}]，最多 4 個；mark 是氣泡角上的大符號（'？' '！'），這句話後面要被推翻就寫 '？' |
| `zoom` | 景別，同 v-host |


必填：`items`

| `items` | [{img, name, tag, at}]，1–2 張：第一張在左，第二張在右 |

### 二、把證據擺出來

#### v-clip

實拍 / 照片放在中間一條寬頻裡，上面一行標題，帶子上疊標籤、數字、人。

| 引數 | 寫什麼 |
|---|---|
| `clip` | 實拍幀序列名（assets/clips/<名字>/） |
| `img` | 或者一張圖 |
| `from` | 實拍從第幾秒開始 |
| `rate` | 倍速 |
| `pos` | 裁切位置，如 '50% 20%' |
| `title` | 帶子上面的標題（可以用 \n 分兩行，<em>重點</em>） |
| `brow` | 標題上面的小字 |
| `tags` | 帶子上的白底標籤，一句出一個，留著不走：[{text:'售價 3 萬', at:'@b03:三萬'}] |
| `num` | 帶子中間的大數字，可以原地變：{from:'$209', to:'$108', at:'@b04:跌', label:'油價'} |
| `person` | 右下角的摳像人：{img:'x.png', name:'某某', grayAt:'@b05'}（grayAt 之後變灰 = 出局） |
| `strip` | 帶子底下的一排小格：[{title:'成本', value:'$2萬', at}]，最多 4 格 |
| `avatar` | 角上要不要她的圓頭像（有口播時預設要，false 關掉） |
| `source` | 素材來源小字 |

```js
{scene:'v-clip', until:'@b03:黃', says:'這次是真在打仗', clip:'smoke', title:'這次<em>真在打</em>', tags:[{text:'油價衝上 $104', at:'@b03:打'}], source:'新聞實拍'},
```

#### v-full

一張圖 / 一段實拍鋪滿整個畫面區，字壓在上面。

| 引數 | 寫什麼 |
|---|---|
| `clip` | 實拍幀序列名 |
| `img` | 或者一張圖 |
| `from` | 實拍從第幾秒開始 |
| `rate` | 倍速 |
| `pos` | 裁切位置 |
| `title` | 壓在上面的標題 |
| `brow` | 小字 |
| `tags` | 標籤，同 v-clip |
| `avatar` | true = 左下角放她的圓頭像 |
| `dim` | 壓暗多少（0–1，預設 .25） |
| `source` | 來源小字 |

```js
{scene:'v-full', until:'@b02', says:'第一眼：這地方長這樣', img:'assets/img/port.jpg', title:'全球最大的<em>免稅店</em>', brow:'海南 · 三亞'},
```

#### v-chapter

換話題：一張章節卡，告訴觀眾"下面講第二件事"。

必填：`title`

| 引數 | 寫什麼 |
|---|---|
| `no` | 序號 '01' |
| `title` | 這一段的名字 |
| `sub` | 一行補充 |

```js
{scene:'v-chapter', until:'@b12', says:'換話題：下面講誰在賺錢', no:'02', title:'誰在賺錢', sub:'三家公司分蛋糕'},
```

#### v-meme

一張梗圖 / 表情 / 截圖拍在中間，配一句吐槽。

必填：`img`

| 引數 | 寫什麼 |
|---|---|
| `img` | 圖片 |
| `caption` | 圖下面的一句話（大字） |
| `title` | 圖上面的標題 |
| `brow` | 小字 |
| `rot` | 歪幾度（預設 -2） |

```js
{scene:'v-meme', until:'@b07', says:'笑一下：網友的反應', img:'assets/img/meme.jpg', caption:'我的錢包：？'},
```

#### v-doc

把原文擺出來：新聞、財報、公告的截圖放在白卡上，重點句刷黃。

必填：`img`

| 引數 | 寫什麼 |
|---|---|
| `img` | 截圖（先裁好） |
| `title` | 上面的標題 |
| `brow` | 小字（如 來源名） |
| `hl` | 刷黃的地方：[{x:.1,y:.3,w:.8,h:.08,at:'@b04:最低'}]，x y w h 是佔截圖寬高的比例 |
| `zh` | 外文原文的中文：{text:'黃金跌到一年多來最低', at} |
| `source` | 來源小字 |
| `pos` | 截圖太長時顯示哪一段（0 頂部–1 底部） |
| `flat` | true = 截圖平著放（預設斜放，上下邊虛一點） |
| `avatar` | 角上要不要她的圓頭像（有口播時預設要，false 關掉） |

```js
{scene:'v-doc', until:'@b08', says:'原文寫著 12 月還要加息', img:'assets/img/doc_cnbc.png', brow:'CNBC 報道', title:'市場怎麼押', hl:[{x:.04,y:.35,w:.87,h:.1,at:'@b07:可'}], zh:{text:'12 月再加息：<em>75%</em> 機率', at:'@b07:還'}},
```

#### v-stack

一條接一條的新聞 / 截圖，啪啪啪摞上來：這事到處都在報。

必填：`items`

| 引數 | 寫什麼 |
|---|---|
| `items` | [{img:'截圖', at}] 或沒有截圖時 [{title:'新聞標題', source:'媒體名', at}]，3–5 張，每張約 1 秒 |
| `title` | 上面的標題 |
| `brow` | 小字 |

```js
{scene:'v-stack', until:'@b04', says:'這事到處都在報', title:'一週三條大新聞', items:[{title:'金價跌破 3900', source:'路透'},{title:'美聯儲再放鷹', source:'彭博'},{title:'油價重回 100 美元', source:'CNBC'}]},
```

#### v-collage

幾張照片拼在一起，一張一張貼上來：這一類東西長這樣。

必填：`items`

| 引數 | 寫什麼 |
|---|---|
| `items` | [{img, label, at}]，2–4 張 |
| `title` | 上面的標題 |
| `brow` | 小字 |

```js
{scene:'v-collage', until:'@b05', says:'這一類車長這樣', title:'都是<em>兩座小車</em>', items:[{img:'assets/img/c1.jpg', label:'Smart'},{img:'assets/img/c2.jpg', label:'宏光 MINI'},{img:'assets/img/c3.jpg', label:'菲亞特 500'}]},
```

#### v-phone

一部手機立在中間，螢幕裡是 App / 網頁 / 聊天截圖，可以往下滑。

必填：`img`

|---|---|
| `img` | 豎版截圖 |
| `scroll` | 這一鏡裡往下滑多少（佔截圖高度的比例，0–1） |
| `title` | 上面的標題 |
| `brow` | 小字 |
| `tags` | 手機兩邊的標籤：[{text, at}]，左右交替，最多 4 個 |

### 三、算賬、比較、講道理

#### v-list

一張清單卡：幾條原因 / 幾個選項 / 幾步，念一條出一條；最後可以落一塊答案。

必填：`items`

| 引數 | 寫什麼 |
|---|---|
| `title` | 卡片上面的標題 |
| `brow` | 小字 |

## 通用寫法

- **顏色**：`color` 寫名字：`'gold'` `'red'` `'green'` `'navy'` `'steel'`。數字漲跌用 `red` / `green`，其餘預設金色。
- **重點字**：標題、引語裡用 `<em>重點</em>` 包住要變色的詞，一行最多一處。
- **數字**：照口播裡的寫法寫成字串：`'6.9%'` `'-6.9%'` `'$104'` `'3.6億'`。負號寫在最前面。
- **時刻**：`at:'@b03:詞'`。不寫 `at` 的 `items` 會在這一鏡裡均勻排開；`'@b07:1+0.3'` 是"b07 第 1 個字之後再等 0.3 秒"。
- **截圖先裁**：`v-doc` 的截圖先裁到只剩要看的那一段（寬高比 1.5:1 到 3:1 最好），再量 `hl` 的比例。整頁截圖放進去，字小到手機上看不清。
- **標籤別抄字幕**：`tags`、`label` 寫字幕裡沒有的資訊（一個數、一個地名、一個來源）。和字幕一模一樣等於沒寫。
- **佔位素材**：`assets/kit/ph/` 裡的圖只為先跑通，成片前全換掉，`--check` 會提醒。

## 一支片怎麼排（照這個配比不會錯）

排法看自三條參考片（每條 5–8 分鐘，各看了開頭、中段、結尾的鏡頭單）：

| 位置 | 放什麼 | 例子 |
|---|---|---|
| 開頭 0–5 秒 | 她全屏直接開口，或一張最反常的圖 / 一個問題 | `v-host` / `v-full` / `v-quiz` / `v-title` |
| 每一段 | 她說觀點 → 1–3 鏡證據 → 回到她 | `v-host` → `v-clip` `v-doc` `v-line` → `v-host-words` |
| 大數出現 | 單獨給一鏡 | `v-host-num` / `v-number` / `v-move` |
| 講"為什麼" | 一條鏈或一張清單 | `v-chain` / `v-list` |
| 60 秒以上換話題 | 章節卡 | `v-chapter` |
| 結尾 | 她全屏，一句大白話；關鍵詞拍在胸前 | `v-host-words` / `v-title` |

- 她露臉的時間大約佔四成；一條 30 秒的片 10–14 鏡（這兩個數是按鏡頭單估的，不是逐幀量的，當參考）。
- 同一個場景不要連著用兩次（`v-host` 換景別不算）。
- 整屏大字（`v-title`）全片最多三次；梗圖最多兩次；選擇題最多一次。

## 常見報錯

| `--check` 說 | 怎麼改 |
|---|---|
| 沒有這個場景 | 場景名寫錯了，直式的都以 `v-` 開頭，對著上面的表改 |
| 缺必填項 | 看上面那個場景的"必填" |
| 這一鏡只有 x 秒，至少要 y 秒 | 把 `until` 往後挪一句，或者把這一鏡和前一鏡並掉；只差 0.2 秒以內可以不改 |
| 字太多放不下 | 按提示的字數刪；長句交給字幕，畫面上只留詞 |
| 找不到圖 / 實拍 | 路徑從影片目錄寫起：`assets/img/x.png`；實拍要在 `counts.json` 登記 |
| 用了佔位素材 | 成片前換成真素材 |

## 往裡加新場景

場景都在 `kit/vert.js`，一個場景一段 `S('v-名字',{says,use,avoid,need,help,draw})`：
- `says` `use` `avoid` 三句大白話必寫，這份文件的表就是從它們生成的；

## 質感靠圖：這幾樣先生圖再填

和參考片並排比，差距最大的不是版式，是"有沒有圖"。下面三處不要拿程式碼畫的扁平示意頂，先生圖（或找圖）：

| 用在哪 | 要什麼圖 | 生圖時怎麼說 |
|---|---|---|
| `v-chain` 每一環的 `img` | 白底小插畫，一環一個物件（油桶、購物車、央行大樓） | 純白背景、單個物件居中、扁平淡彩、不帶字、方圖 |
| `v-title` 的 `pic` | 橫圖，暗底，一個和關鍵詞對應的物件（百分號雕塑、金條） | 深色背景、金屬質感、物件居中偏上、四周留空、不帶字 |
| `v-doc` 的 `img` | 真的報道 / 財報截圖，裁到只剩標題和那兩三行 | 不生圖，去原網頁截 |

插畫拿到以後把底色推成純白再用（不然白板上會露出一塊灰方塊）。截圖裡要劃熒光筆的那句，別放在最右邊 10% 裡：截圖是斜著放的，右邊會收窄。
