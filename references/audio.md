# 聲音

## 文案（配音之前）

- 口語、第一人稱，像在跟朋友算賬，不要“AI 腔”的排比和總結句。如果使用者有自己的口播語料，照著他的說法寫。
- 每一句都要接住上一句。寫完通讀一遍，看有沒有哪句是憑空冒出來的。
- 插原聲的地方先寫一句鋪墊，告訴觀眾接下來是誰、他會說什麼性質的話：“難怪某某總愛說這句：”“連某某自己都說：”。
- 使用者點頭之前不做正式配音。

## 配音：先用臨時語音

**第一步：臨時配音**（`scripts/temp_voice.py`）。用免費的 edge-tts（預設“雲希” `zh-TW-YunJheNeural`）給每句話出一條，同時生成 `timeline.json`，裡面有每個字的時刻、原聲插段和片名的位置。畫面全部掛在這些字的時刻上（`cue(句id, '詞')`），所以後面換了配音，畫面會自動順延。

**第二步：正式配音**（文案和畫面都定了以後）。正式配音可以是任何 TTS、克隆音色或真人錄音，每句存成 `voice/<句子id>.final.wav`，然後：

```bash
python scripts/temp_voice.py film/script.json --asr
```

它會換上正式配音、切掉靜音，並用 faster-whisper 重新逐字對齊。

**所有配音都這樣處理：**
- 每句先切掉首尾靜音，再按 `gap` 留停頓，一般 0.35 秒，換段處 0.5 秒。不切靜音的話，每句前後會帶 0.2–0.6 秒空白，再加上停頓，節奏會時長時短。
- **保持原速，不要用 atempo 事後加速。** 切掉靜音後再拉到 1.1 倍，聽感會很急促。要說得快一點，就在生成時調語速（edge-tts 的 `rate`，或正式 TTS 自己的語速引數）。
- 逐字對齊的鍵用完整的句子編號。只截前幾個字元當鍵的話，“b10b”會覆蓋“b10”，字幕和卡點就全錯了。

## 原聲

見 `sourcing.md` 的原聲一節。混音時，原聲和配音放在同一條人聲匯流排上，這樣配樂會自動給它讓路。原聲和配音的響度差在 2dB 以內（`mix.py --check`）。

## 音效和配樂

音效只跟畫面裡的動作走，一個動作一聲，同一時刻只留一個。實踐中驗證過的口味：
- 鏡頭沿桌面滑過去、搖去找下一個：很輕的 whoosh。
- 橫推換人、畫框甩進來、推近畫框：電影感的快 whoosh。
- 巨字立起來、身後換背景：一聲低沉的撞擊。
- 累加滾數：滾的時候一條短的上升音，停在那個數上時一聲電影感撞擊。片名也用電影感撞擊。
- 原文倒成桌面、兩個世界之間的虛化過渡：低沉的 whoosh。
- 開頭如果用關鍵詞快閃：每張一聲很輕的翻書。
- 資金流動的管子：很輕的 whoosh。
- **不用**：金幣、收銀機、籌碼這類卡通化的“錢”音效；緊張的滴答配樂和放映機聲，容易顯得怪。

配樂用一條平穩的底樂，壓在配音下面約 18dB，人聲出來時 sidechain 自動壓低，片名期間抬高。素材推薦從 Openverse 檢索 CC0 的（`https://api.openverse.org/v1/audio/?q=…&license=cc0`），並把來源記進清單。

如果沒法親耳聽（比如由 AI 代理混音）：
- 按峰值歸一每個音效（`mix.py` 的 `peak` 引數），不靠猜音量；
- 混完量響度：開頭、配音、每段原聲都要量；
- 交付時請使用者重點聽原聲的剪口和語速。

`scripts/mix.py` 已經實現了上面這些：配音、原聲、音效、配樂，最後到 -14 LUFS。

- **臨時配音連不上（edge-tts 報 NoAudioReceived）**：不用等它，直接用正式配音，每句存成 `voice/<句子id>.final.wav` 再跑 `temp_voice.py script.json`。逐字對齊要用 whisper：設環境變數 `WHISPER_MODEL` 指向本機的模型資料夾，只寫模型名會連網核對，網不好會一直等。
