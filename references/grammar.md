# 鏡頭怎麼接

每個邊界先回答“上一鏡留下什麼、下一鏡要看什麼、靠什麼接”，再從下面挑一種走法。下面寫的是機制和什麼時候用；畫面每條片現寫。走法只交接注意力，不帶新資訊，也不挪動配音和字幕的時間點。原理和量化目標在 `motion.md`。

標了 `M.xxx` 的走法，`scripts/moves.js` 裡有現成的動作。意思對得上才用，只是差不多就手寫（`motion.md` 的手法庫）。

## 動作的手感（全片統一）

- **動的是鏡頭**：一鏡的機位 = 起點 + 幾次移動 + 中間慢漂。
  - 移動 0.5–1.1 秒，ease-in-out；落點就是正在講的那個東西；
  - 兩次移動之間慢漂，多半往裡推。參考片約 3%/秒；`camPath` 的 drift 填 0.016–0.025 就能量到這個數。
  - 用 `scripts/stage25d.js` 的 `camPath`。
- **有前後層**：底 z≈0.3、字 z≈0.7、人和圖形 z=1、前景 z>1。鏡頭一動，遠的動得少。
- **快就帶運動模糊**：按這一幀挪了多少畫素加方向模糊（`L()` 自動算）；停下就清楚。
- **東西自己出現得很樸素**：淡入約 0.25 秒（可以帶十幾畫素的位移），或者切過來時已經在。巨字可以 0.3 秒從 1.12 倍長到 1。不回彈、不過沖、不打字機、不掃光。
- **狀態變化代替入場**：變亮、變灰、變色、被套住、被點亮，都是在原地發生。
- 時長：小元素 0.2–0.35 秒；換焦點或重新取景 0.5–1 秒；橫推、甩入 0.3–0.4 秒。

## 走法

**帶過：同一個物件跨鏡頭**
- 7250 億：從四張新聞卡上累加出來 → 縮成片名的眉題 → 回到畫面中間當錨（底下實拍在換）→ 升到上方分出兩條線 → 結尾立成紅柱 → 被四家押注。
- 要求：身份、顏色、比例不變；在上一鏡的末態裡已經在，下一鏡一開場就在。

**釘住一個東西，底下換實拍**（`M.montage`）
- 片名和 7250 億釘在中間，底下的資料中心實拍（壓暗、去色）0.42 秒換一座，一直換到“晶片”兩個字出來。
- 也可以把上一鏡的圓盤縮成徽章釘在角上，底下連切幾鏡實拍。

**沿著桌面滑過去：唸到哪個，鏡頭到哪個**
- 四家的新聞卡平鋪在一張透視桌面上，唸到谷歌、微軟、亞馬遜、Meta 時，鏡頭沿桌面滑到那一張（0.4 秒），唸到才亮，沒念到的壓暗；“這四家”抬高看全。
- 比“一張張砸到最上面”好：東西早就在，鏡頭去找它。

**平面倒成桌面**（`M.layFlat` + `M.standUp`）
- 前面的東西講完了、還要留作背景時，整層轉到透視平面上（約 60°）、下沉、壓暗到 0.3，新的主角從下面立起來。
- 例：“加起來”時四張卡倒平、退成底，7250 億立在上面滾；路透原文倒平，累計淨燒的圖表立在上面。

**推近：畫框變成下一鏡**（`M.frameFill`）
- “晶片”畫框推滿屏（0.45 秒，中間略虛）→ 黃仁勳臺上的實拍從 1.08 倍收到 1 →“賣晶片的英偉達”。推近的是同一份東西，不換成一張相似的圖。

**人身後換背景**（`M.bgSwap`）
- 先放實拍原片；說到關鍵詞那一幀，同一個人的摳像壓到新底上，位置和原片一模一樣，看不出接縫；巨字在他身後長出來；再用 0.6 秒把人挪到構圖位置、放大（`cutP` 的 track 從 0 走到 1）。
- 例：“市值”時黃仁勳身後的舞臺換成英偉達的綠，“5.2 | 萬億”分在他頭兩側。

**人站在巨字前面，字隨話翻**（翻字用 `M.megaFlip`）
- 同一個人、同一個底，字換一句：“全世界最值錢”時“5.2 萬億”往下滑出、“全球第一”從上面落下（0.24 秒，豎向模糊）。挑原片裡有動作的那一段對上這句（他正好張開雙手）。

**橫推換人**（`M.pushSwap`）
- 整組（底 + 字 + 人）0.4 秒橫推出畫，新的一組從另一邊推進來，兩組都帶方向模糊。新一組的底換成這家的顏色。
- 例：黃仁勳連字帶人往左推走，Altman 帶著青色的底推進來。

**卡片在人旁邊冒出來，焦點移過去**（`M.cardFocus`）
- 說到“收入”時，Altman 肩旁冒一張小卡“$360 億”（淡入加一點上移）；同時他身後的“8520 億”虛掉、壓暗一半，鏡頭往卡片那邊挪一點。大字和小卡同框，大小對比自己說話。

**底下換成實拍**
- “光是算力”：圖表縮到左邊；它身後的桌面換成星門工地的實拍（壓暗），8560 億立在右邊，和左邊的 2780 一比，不用說出來。

**上一鏡虛化當底**（`M.blurToBase`）
- 工地實拍 0.45 秒裡模糊到約 26px、壓暗到 0.4，退成資金迴圈桌面出現的那一刻。用在兩個世界之間、又沒有物件可帶的時候。

**同一個世界裡換機位：鏡頭去找正在說的那一個**（機位用 `S25.camKeys`，桌面用 `S25.desk3d`）
- 資金迴圈：
  - “從哪來”在 OpenAI 上慢漂；
  - “英偉達”時鏡頭搖過去找到它（它一直在桌上，只是在畫外）；
  - 錢流到哪，鏡頭跟到哪；
  - “轉了一圈”拉回看全；
  - “回到英偉達手裡”推到英偉達，其餘壓暗。
- 機位用關鍵幀表（時刻 → x、y、z），兩點之間 ease-in-out，最後一個點之後繼續慢推。

**證據小卡：從相關的地方彈出來，看完縮回去**（`M.popWindow`）
- “英偉達投錢給 OpenAI”：CNBC 的實拍從“投資”箭頭旁邊彈成一張白邊小卡，背景壓暗；讀完縮回箭頭，桌面沒有離場。不要切成全屏打斷這張關係圖。

**人 ↔ 圓盤、盤撐開成視窗**
- 實拍縮成盤：`clip-path: circle()` 把全屏實拍收到盤的半徑，圓心同時挪到盤的位置，盤在後半段淡入。
- 盤撐開成視窗（`M.popWindow`）：錢回到英偉達後，從盤的位置把黃仁勳的原聲視窗撐開（大小、圓角、位置一起變），說完再縮回。盤在螢幕上的位置要在渲出來的幀上實測，鏡頭推近以後它不在原座標。

**鏡頭沿著差距走**
- 柱狀圖從低機位拍：紅柱長出來時鏡頭跟著往上；“收回來的”搖到旁邊那根矮柱；“差著一大截”鏡頭沿著差的那一段往上抬，括號跟著畫出來。
- 鏡頭推近時，柱子下面的說明字收掉，免得壓字幕。

**推過鏡頭：換舞臺時，上一鏡的末幀衝過來**（`M.pushThrough`）
- 上一鏡最後一幀放大到 1.3–1.7 倍、模糊 12–14px、淡出（0.25–0.3 秒），蓋在新一鏡上。
- 結尾 Meta 籌碼推過鏡頭接扎克伯格本人，放大中心對準那枚籌碼，放大到 4 倍。

**押注：開頭的東西在結尾回來**
- 開頭那四家公司的 logo，在“大家都在賭”時一枚枚沿地面推到差額那一段上；“連扎克伯格自己都說”時只有 Meta 亮起，鏡頭推過去。首尾呼應，不需要解釋。

**開頭鉤子**（關鍵詞快閃、一個數砸下來、反差並排、懸念迴圈……）：每條片選一種，見 `opening.md`。

## 走法 → 模板裡怎麼寫（模板檔）

模板檔裡，鏡頭之間怎麼接只有兩種寫法：這一鏡的 `enter`，或者下一鏡一開場就放上一鏡留下的那樣東西（"帶過"）。`enter` 只有這幾個：`cut`（預設）`flat` `push` `push-right` `through` `blur` `whip` `whip-left` `fade`。同一種不連著用（`--check` 會提醒）。

| 走法 | 模板裡怎麼寫 |
|---|---|
| 帶過：同一個物件跨鏡頭 | 沒有專門的引數，下一鏡的引數裡寫同一個東西。同一個數：`number` 的 `value` → `title` 的 `brow` → `montage`/`frames` 的 `pin`（`kit/demo/film.js` 第 3–5 鏡）；同一個人：先 `person`，之後的 `discs` 用他的 `photo`；同一家公司：每一鏡同一個 `color` |
| 釘住一個東西，底下換實拍 | `montage`（`pin` + `items`）、`title`（`items`；只給一段實拍就連續放，實拍退成底）；上一鏡的圓盤釘在角上：`footage` 的 `badge` |
| 沿著桌面滑過去 | `desk`：`items[].at` 唸到哪張滑到哪張，`all` 抬高看全；唸到證據時 `read:{i, at}` 把桌面抬平、推近刷黃那一張的 `hl`（`kit/demo/film.js` 第 18 鏡） |
| 平面倒成桌面 | 下一鏡 `enter:'flat'`，接 `number`（數從下面立起來）或 `chart`（圖表從桌面上立起來）（`kit/demo/film.js` 第 3 鏡、第 10 鏡）。能接 flat 的只有 `number` `chart` `equation` `change` `stats` 和不帶 `items` 的 `title` `statement` |
| 推近：畫框變成下一鏡 | `frames` 的 `fill:{i, at}` + 下一鏡同一份素材的 `footage`，寫 `settle:true`（`kit/demo/film.js` 第 5–6 鏡） |
| 人身後換背景 | `person` 的 `from:{img, at}` |
| 人站在巨字前面，字隨話翻 | `person` 的 `words` + `flip` |
| 橫推換人 | 下一鏡 `enter:'push'`，兩鏡都是 `person` |
| 卡片在人旁邊冒出來 | `person` 的 `cards` |
| 底下換成實拍（圖表縮到一邊，身後換工地實拍） | 沒有模板：`custom` |
| 上一鏡虛化當底 | 下一鏡 `enter:'blur'` |
| 同一個世界裡換機位 | board 系列：節點的 `at`，`steps` 的 `focus` / `light` / `show` |
| 證據小卡 | board 系列 `steps` 的 `pop:{img 或 clip, from, back}`（`kit/demo/film.js` 第 11 鏡）；別的場景之後用 `scene:'popup'`：上一鏡凍住壓暗、視窗撐開（`kit/demo/film.js` 第 19 鏡，接在新聞桌面後面，從"追著問"開始） |
| 人 ↔ 圓盤、盤撐開成視窗 | 盤撐開成視窗：`pop` 的 `from` 寫他的圓盤 id，`clip` 放他的原聲實拍；實拍縮成盤：沒有模板，`custom` |
| 鏡頭沿著差距走 | `bars` 的 `gap`；排行榜：`ranking` 的 `climb` |
| 推過鏡頭 | 下一鏡 `enter:'through'`，`throughAt:[x,y]` 對準要衝進去的那個東西 |
| 押注：開頭的東西在結尾回來 | 用"帶過"：結尾那一鏡再用開頭那幾家的 `photo` 和 `color`；推過去的動作手寫 |
| 開頭鉤子 | `flash`、`headlines`、`number`、`versus`、`equation`……按這支片的料選，見 `opening.md` 和 `rules.md` 的決策表 |

## 別這樣

- 每個切點都套一個特效。
- 元素各自演入場：一個個彈出來排隊、整體重排、貼上皇冠和徽章。
- 一整張平面一起縮放當“運鏡”，或者鏡頭沒有目標地往外拉。
- 東西擺好以後整屏定住兩三秒以上。
- 連續硬切幾次，每次都要觀眾重新找位置。
- 用閃白、飛紙、通用遮罩去蓋一個沒有理由的切換。
- 東西憑空出現：新東西要從它來的地方進場（箭頭、上一個數、畫框），或者本來就在、鏡頭去找它。
