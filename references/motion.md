# 動效：為什麼參考片不像 PPT、不像 AI

下面的結論來自：三條同類參考片全片逐幀量鏡頭運動（去掉整屏主持人，只比 B-roll），23 段關鍵動作拆成連續幀，再和示例片被否的早期版本逐項對比。
參考片的連續幀不隨倉庫提供。想看某個動作怎麼走，拿你自己的參考片用 `scripts/strip.py` 拆成一個動作 8 張的連續幀對照。

## 一句話

**參考片的"動"，是鏡頭在一個有前後層的世界裡走、東西在原地換狀態，每一下都對著那句話的意思。PPT 的"動"，是每個元素自己演一段入場動畫、整張平面一起縮放。**
**AI 味來自兩樣：假裝真實的通用大片當牆紙（熔爐、賭場、晶片神殿），和什麼都在發光。**

慢推、數字滾動、實拍上壓字，參考片都在用。示例片早期把這幾樣當成禁令，影片就死了：問題不在手法，在做法。

## 做每個動作前問三句

1. **刪掉它，觀眾少懂了什麼？** 什麼都沒少，就是裝飾，刪。
2. **是鏡頭在走、東西在換狀態，還是元素自己在演入場？** 元素自己演，就改成鏡頭運動或者狀態變化。
3. **這一層是真的、具體的東西嗎？** 假裝真實的氛圍圖，換成真素材，或者換成明說是設計出來的抽象底。

這是判斷標準，不是禁令。

## 五條原理

**1. 動的是鏡頭和世界，不是元素。**
東西出現得很樸素：淡入約 0.25 秒，或者切過來時已經在那兒了。大運動交給鏡頭：在同一張關係圖裡推到一個節點、拉回全域性、搖到旁邊。或者交給原地換狀態：小圓盤被大圓盤套住（= 收購）、節點變灰（= 出局）、連線變紅（= 風險）。
早期的做法：圓盤一個個彈出來排一排，再整體重排成田字格；皇冠、NO.1 貼上去；數字帶模糊砸進來。

**2. 每一下動作都是內容。**
推近 = 看這個，拉遠 = 整體是這樣，巢狀 = 吞下，換背景 = 現在說到這個世界，橫推換人 = 換一個人說。刪掉動作，意思就少一塊。

**3. 有空間：前後層、景深、運動模糊。**
一幀裡有好幾層：遠處的底紋、上一鏡退成的虛化背景、圖形、摳出來的人、前景的煙或粒子。鏡頭一動，遠的動得少、近的動得多。快的東西帶方向模糊，不講的東西壓暗、去飽和或者虛掉。
早期的做法：所有東西在一個平面上，一推全部同比例放大。鏡頭在動時，"各處動得不一樣"的比例只有 30%，參考片是 52–62%。

**4. 節奏來自剪輯，不來自特效。**
一鏡的節奏：快速換位（0.5–1 秒，兩頭緩、中間快）→ 慢漂（約 3%/秒，多半往裡推）→ 下一刀。B-roll 大約 2 秒換一個畫面，幾乎沒有超過 2 秒完全不動的時候。
早期的做法：一鏡 4–6 秒，靠元素入場撐場面；或者東西擺好以後整屏定住 2–9 秒。

**5. 一個畫面一個主角，其餘讓路。**
正在講的那個亮著，其餘壓暗、去飽和或者虛掉。早期的做法：圓盤、數字、名牌、背景燈光一起發光，同樣的強調等於沒有強調。

## 為什麼不像 AI

- **真東西當主角。** 人、地方、檔案都是真的。生成的東西只演一個拍不到的具體比喻：蛇吞象、兩棟只差招牌的樓、穩定幣。生成物件要和真素材同光、同調色，有投影、有景深，放進同一個空間裡。
- **背景要麼是設計出來的抽象世界，要麼就是內容本身。** 一支片定一片抽象底（深色織物、這一段的品牌色光），不假裝是真實場景。實拍出現時，實拍就是在講的東西。
- 早期的做法：熔爐、賭場、晶片神殿、夜景園區這類 AI 寫實大片，壓暗後墊在所有圖形底下。

## 三個最容易做壞的手法

**數字滾動**
- 只在"累加、越來越多"本身就是意思的時候滾：幾家加起來、按年份累計、一筆筆流進來。一支片最多一兩次。
- 寫滿位數（`$725,000,000,000`），跳動的位數本身在說"有多大"。滾的時候按十億取整，後面全是 0（參考片也是這樣），不要出現 `$565,771,715,768` 這種亂碼一樣的數。
- 起點要有意思：從第一筆開始（比如第一家的 1800 億），不從隨便一個數開始。
- 話說到那個數時正好停，停下的那一刻配一聲低沉的撞擊。
- 滾的數放進場景裡：前面的東西倒成桌面當底，數字立在上面。
- 早期的做法：每個數都滾，從 3332 滾到 8520。"八千五百二十億"這句話本身沒有累加，滾它就是裝飾。

**實拍上壓字**
- 只有兩種壓法：
  - **人在字前面**：把人摳出來，巨字夾在人和底中間，人站在兩組字的空當裡，字只有一兩個詞。字和人是一張海報，人還在動。
  - **實拍退成底**：實拍壓暗（亮度約 0.36）、去色（約 0.5）、略虛（約 1px），字是主角。片名、章節卡、開頭的釘字都這樣。
- 早期的做法：在清楚的實拍上貼名牌框（電視臺下三分之一模板），或者把字放在 AI 牆紙上。

**慢推**
- 推是機位朝一個目標在走，目標就是正在講的那個東西。場景有前後層，推起來才有空間感。先快速推到位，再慢慢漂。
- 早期的做法：整張平面一起縮放，沒有目標，多半在往外拉，每一鏡都一樣。

|---|---|---|---|---|

| 定住超過 2 秒 | 0.6–1.0 次/分 | 2.0 | **3.9** | 0 |
| 鏡頭在動的時間 | 21–27% | 19% | 10% | 24% |
| 鏡頭動時各處動得不一樣 | 52–62% | **30%** | — | — |
| 有前後層的鏡頭運動 | 9–12% | **2.8%** | 7% | 10% |
| 往裡推 : 往外拉 | 1.3–2.9 : 1 | **0.4 : 1** | 1.2 : 1 | 2.1 : 1 |

## 手法清單

按"這句話在說什麼"選，不是挨個用一遍。引數是起點。

| 手法 | 它在說什麼 | 怎麼做 |
|---|---|---|
| **人摳像壓巨字** | 這個人 = 這個詞（市值、估值、帝國、權） | 實拍逐幀摳人（`scripts/matte.py`）；三層：底（z≈0.3）→ 巨字（z≈0.7）→ 人（z=1）；人釘在畫面中間（按每幀頭肩中心跟住他），字分兩組放在他頭的兩側；字在 0.3 秒裡從 1.12 倍長到 1；鏡頭慢推 |
| **人身後換背景** | 話題換到另一個世界，人還是那個人 | 先放實拍原片；說到關鍵詞那一幀，同一個人的摳像壓到新底上（位置一模一樣，看不出接縫），再用 0.6 秒挪到構圖位置、放大 |
| **橫推換人** | 換一個人、換一件事 | 整組（底 + 字 + 人）0.4 秒橫推出畫，新的一組從另一邊推進來，兩組都帶方向模糊 |
| **卡片在人旁邊冒出來** | 他說的這幾樣東西 | 跟著字出現，淡入 0.25 秒加一點上移；同時焦點從巨字挪到卡片（巨字虛掉、壓暗），鏡頭往卡片那邊挪一點 |
| **東西拿在手上** | 他手裡握著這個 | 摳像加素材貼紙，掛在手的位置，素材自己有小動作（轉、閃） |
| **釘住一個東西，底下換實拍** | 這件事 = 這些畫面 | 前景（標題、數字、圓盤徽章）不動，底層實拍 0.4–1 秒一刀，壓暗去色 |
| **同一個世界裡換機位** | 看這個 → 看整體 → 看旁邊 | 2.5D 相機：一鏡一個落點，落點就是正在講的那個；新東西在世界裡早就擺好了，鏡頭搖過去"找到"它，而不是它滑進來；移動 0.6–1.1 秒，兩頭緩；中間慢漂 |
| **平面倒成桌面** | 前面的東西退成背景，新東西站在上面 | 整層轉到透視平面上（rotateX 約 60°）、下沉、壓暗到 0.3；新主角（圖表、數字）從下面立起來 |
| **甩出 / 推進來** | 換一個畫框、換一個物件 | 0.25–0.35 秒位移，配方向模糊（SVG `feGaussianBlur stdDeviation="x 0"`，按這一幀挪了多少畫素挑檔） |
| **上一鏡虛化當底** | 從全域性裡拎出一個人或一件事 | 上一鏡最後一幀模糊約 20px、壓暗到 0.4，0.4 秒裡退成新一鏡的底 |
| **鏡頭沿著差距走** | 差得有多大 | 柱狀圖鏡頭從矮柱搖到高柱頂，或者沿著差的那一段往上抬；括號跟著鏡頭畫出來 |
| **真火、煙、粒子疊層** | 章節的情緒、揭曉的一下 | 真實素材用濾色疊加；只在章節卡和揭曉處用 |
| **生成的比喻物件** | 拍不到的東西 | 只生成具體物件（一枚幣、一座樓、一條蛇），摳出來放進前後層，同光同調色；寫實的標"AI生成" |
| **開頭預告本片的圖** | 後面有好東西 | 0.5 秒一張，閃過本片後面會出現的幾張圖 |

## 手法 → 模板裡怎麼寫（模板檔）

模板檔裡，上面這些手法已經做進場景和接法：動作的時長、方向、前後層、模糊都調好了，鏡頭表裡寫引數就行。還是先寫 `says`，意思對得上才用。引數以 `kit/scenes.js` 每個場景的 `help` 為準，例子在 `kit/README.md`。

| 手法 | 模板裡怎麼寫 |
|---|---|
| 人摳像壓巨字 | `scene:'person'`：`img`（摳像）+ `words:['5.2','萬億']` + `color` |
| 人身後換背景 | `person` 的 `from:{img:'原照片', at:'@b06:市值'}`（摳圖和原照片同尺寸） |
| 巨字隨話翻 | `person` 的 `flip:[{at, words}]` |
| 橫推換人 | 下一鏡寫 `enter:'push'`（兩鏡都是 `person`；`'push-right'` 往右推） |
| 卡片在人旁邊冒出來 | `person` 的 `cards:[{at, label, value}]`；大數旁邊冒小卡：`number` 的 `sub:{label, value, at}` |
| 釘住一個東西，底下換實拍 | `montage` 的 `pin` + `items`；片名釘住：`title` 的 `items`；金句：`statement` 的 `items`（`title`、`statement` 只給一段實拍時連續放，就是"實拍退成底"）；圓盤徽章釘在角上：`footage` 的 `badge` |
| 同一個世界裡換機位 | board 系列：節點的 `at`，`steps` 的 `focus:id / [ids] / 'all'`；只亮不動鏡頭用 `light`，出現並放寬看全用 `show` |
| 平面倒成桌面 | 下一鏡寫 `enter:'flat'`，接 `number`、`chart`（新主角立在倒下去的上一鏡上；圖表會從桌面上立起來）。能接 flat 的只有 `number` `chart` `equation` `change` `stats` 和不帶 `items` 的 `title` `statement` |
| 甩出 / 推進來 | 畫框：`frames` 的 `items[].at`（唸到一樣甩進來一樣）；整鏡：`enter:'whip'` / `'whip-left'` |
| 上一鏡虛化當底 | `enter:'blur'` |
| 鏡頭沿著差距走 | `bars` 的 `gap:{at, a, b, text}`；排行榜從末尾走到第一名：`ranking` 的 `climb` |
| 推過鏡頭 | `enter:'through'`（`throughAt:[x,y]` 對準要衝進去的那個東西，`throughScale` 放大倍數，預設 1.6） |
| 畫框推滿屏 | `frames` 的 `fill:{i, at}` + 下一鏡同一份素材的 `footage`，寫 `settle:true` |
| 證據小卡、反應窗 | board 系列 `steps` 裡寫 `pop:{img 或 clip, from:節點或連線id, back:'@…'}`；不在 board 裡：`scene:'popup'`，上一鏡凍住壓暗，視窗撐開（`kit/demo/film.js` 第 19 鏡接在新聞桌面後面，從"追著問"開始） |
| 累加滾數 | `number` 的 `roll:{from, at, stop}`；board 裡 `num` 節點 + `roll:{id, from, until}` 步驟；`chart` 的 `total:{label, from, to}`（跟著線滾）。一支片最多兩處 |
| 慢推（實拍） | `footage` 的 `push:[1,1.06]` + `focus:[x,y]`（往哪一點推） |
| 原地換狀態 | board 系列 `steps`：`nest:[裡,外]`（收購）、`gray`（出局）、`mark:{id:'ok'}` / `{id:'no'}`（成不成立）、`link`（線畫出來）、`flow`（錢在走）、`loop`（轉了一圈）、`tag`（價籤換數） |

| 關鍵詞快閃 | `scene:'flash'` |
| 標題牆 → 一句 | `headlines` 的 `pick` + `mark` |
| 按真實比例的反差 | `versus`（圓盤面積按 `tag.value`） |
| 地圖上飛過去 | `map` 節點的 `at`，或者 `steps` 的 `focus`：隔得遠自動先拉遠再推近 |
| 前後層、景深、運動模糊、慢漂 | 模板自動做。board 系列可調 `drift`（慢漂，預設 0.018）、`dof:false`（關掉景深） |
| 先看一個往裡推、先看整體往外拉（開場） | board 系列自動（要改寫 `intro:'push'` / `'pull'` / `'none'`） |
| 東西拿在手上、真火煙粒子疊層、生成的比喻物件、開頭預告本片的圖、底下換成實拍（圖表縮到一邊，身後換實拍） | 沒有模板：`scene:'custom'` 手寫，照上面的手法清單和下面的手法庫 |

## 手法庫（`scripts/moves.js`）

複用是為了品質穩定：這些動作在第六版裡磨過、逐幀查過，用它們就不會再摔同樣的跤（橫推的前幾幀露出採訪者、模糊加太多糊成一片）。複用不是為了湊出一支片。

怎麼選：
1. 先想這一鏡要說什麼（導演表裡"觀眾多懂了什麼"那一格），再來下面這張表找"說的是"對得上的那一行。
2. 選最適配的，不是選能用的。對得上才用，並且在呼叫裡寫 `why`：這一下在說什麼。
3. 只是"差不多"、或者要大改引數才塞得進去，就手寫。手寫的鏡頭和用庫的一樣算數：第六版 14 鏡裡 4 鏡全手寫（快閃、算力、柱狀圖、押注），其餘也是手寫畫面裡插一兩個手法。
4. 庫只管動作的時間、方向、前後層、模糊。畫面裡的人、字、顏色、位置都由這支片自己傳，不要照著第六版填。

| 函式 | 說的是 | 不適配的時候 |
|---|---|---|
| `pushSwap` 橫推換人 | 換一個人、換一件並列的事來說 | 下一鏡不是另一個人或並列的事（比如接圖表）；上一鏡也是橫推進來的 |
| `bgSwap` 人身後換背景 | 話題換到另一個世界，人還是那個人 | 沒有一段無切點、人在動的實拍可摳；人在原片裡太小或被擋住 |
| `megaFlip` 巨字隨話翻 | 同一個人，換一個說法 | 新舊兩句不是同一件事的兩面；人已經換了（那是 pushSwap） |
| `cardFocus` 卡片在人旁邊冒出來 | 他說到的這樣東西，和身後的大字一比 | 小卡和大字之間沒有可比的關係；卡上要放一大段字 |
| `frameFill` 畫框推滿屏 | 推近這份東西，接著講它背後的人或事 | 下一鏡不是畫框裡的同一份東西，只是想換個畫面 |
| `whipIn` 甩進來 | 又來了一樣東西，幾樣要同時停在畫面上 | 東西本來就在世界裡（讓鏡頭去找它）；一個個排隊甩進來 |
| `layFlat` + `standUp` 倒成桌面、新主角立起來 | 前面的講完了退成底，新東西站在它上面 | 前面的東西后面用不上了（直接切，或者推過鏡頭） |
| `montage` 釘住一個東西、底下換實拍 | 這件事 = 這些畫面 | 前景沒有釘住的視線落點；底下的實拍要觀眾看清 |

## 程式碼手感

- **2.5D 相機**：機位 `{x,y,s}` 是焦平面（z=1）上畫面中心對著的點和放大倍數。深度 z 的層：`scale = 1 + (s-1)·z`，平移 `-(x-960)·z`。遠的層 z<1，所以動得少。
- 一鏡的機位 = 起點 + 幾次移動（每次 d 秒，ease-in-out）+ 兩次移動之間慢推。`camPath` 的 drift 填 0.016–0.025：第六版這樣填，量出來慢漂 3.0%/秒，落在參考片的 2.8–3.6 裡。同一個 t 永遠算出同一個機位（逐幀渲染是確定的）。
- **運動模糊**：用上一幀（t−1/30）的機位算這一層在螢幕上挪了多少畫素，按這個量挑一檔方向模糊；推拉太快時再加一點整體虛。
- **景深**：離鏡頭對著的點越遠越虛（最多約 5px）；不講的東西亮度降到 0.4、飽和降一半。
- **摳像跟人走**：`matte.py` 會寫出每幀頭肩的中心 `box.json:cx`。放人時按這一幀的中心對齊，人在原片裡走動，畫面裡他就釘在你要的位置（等於攝影師在跟拍）。
- 這些都封裝在 `scripts/stage25d.js` 裡（只是工具函式，不是鏡頭）。
