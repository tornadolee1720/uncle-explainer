# 硬規則

做影片必須守的規則。每條有編號、能檢查。弱一些的模型可能看不了圖，就靠這份和 `render.mjs --check` 的文字把關。手寫檔也守（除了專講模板引數的那幾處）。

最後一欄是怎麼查：

- **自動**：`node scripts/render.mjs --dir <影片> --check` 會查。寫錯的直接報錯（必須改），其餘在"要看一眼"裡提醒。
- **部分**：`--check` 只查一部分，剩下的自己查。
- **手查**：對著鏡頭表（`film.js`）、`script.json`、`out/sheet.png` 自己查。

提醒不是禁令：每一條都答得上"為什麼這裡就該這樣"，就可以留著。規則為什麼這麼定，看每組後面的出處。

`--check` 會自動查（全部或一部分）的：第 1、3、7–13、15、17、18、20–28、30–32、41 條，還有最後"配額"表裡的金句、章節卡數量。

## 一、每一鏡說什麼

| # | 規則 | 怎麼查 | 查法 |
|---|---|---|---|
| 1 | 每一鏡寫 `says`：一句話，說這一鏡讓觀眾多懂了什麼 | 讀出來是"觀眾懂了：……"，不是"畫面上有……"。說不出來，就是這一鏡還沒想清楚 | 自動（沒寫會提醒） |
| 2 | 先有 `says`，再按"這句話在說什麼"選場景（本文最後的決策表）。不按順序套，不為了換花樣選 | 每鏡的場景都能在決策表裡找到對得上的那一行；只是"差不多"就換一個，或者 `custom` | 手查 |
| 3 | 一鏡一個主角：正在講的那個亮著，其餘壓暗、變灰 | 用一句話說出這一鏡的主角（一個人、一個數、一張原文）。說出兩個，就拆鏡，或者用 `focus`/`light` 一次只亮一個 | 部分（巨字超過兩組，畫框、卡片、對比行、截圖的張數超了會提醒） |
| 4 | 每一鏡接住上一鏡的一樣東西（同一個數、人、畫框、原文）；接不住，要說得出為什麼切 | 導演表的"承接"一列每鏡都有 | 手查 |
| 5 | 東西樸素出現，鏡頭去找：用節點的 `at`、`steps` 把"出現、亮起"掛在唸到的字上，不另加入場動畫 | `custom` 裡沒有彈出、回彈、打字機、掃光、整體重排、帶模糊砸進來 | 手查（模板自己就是這麼動的） |
| 6 | 圖形只演錢和關係：多少錢、誰和誰、誰大誰小、錢怎麼流。"是誰、在哪、什麼產品"用真素材說 | 每個圖形鏡（數、圓盤、柱子、圖表）說得出它演的是哪筆錢、哪個關係 | 手查 |

## 決策表：這句話在說什麼 → 用哪個場景

先寫 `says`，再在這裡找意思對得上的那一行。"別用"那一欄對上了，就換括號裡的場景。33 個場景都在這裡；引數和例子在 `kit/README.md`。

**數和錢**

| 這句話在說什麼 | 用 | 什麼時候別用（換成） |
|---|---|---|
| 一個決定性的數（金額、估值、市值），這句話的落點就是它 | `number` | 一句裡要比兩三個數（`bars` / `stats`）；數後面馬上要拆構成（`network` / `board`） |
| 一筆賬：幾個數一算得出結果（攤到每天、幾家相加） | `equation` | 超過 5 項（拆成兩步）；結果不是這句話的落點（`number`） |
| 同一個數從多少變成多少（漲了幾倍、跌了九成） | `change` | 中間還有好幾個階段（`chart` / `timeline`）；兩個數不是同一樣東西（`bars` / `versus`） |
| 兩到四個數排開認一認（營收、利潤、市值） | `stats` | 要比大小（`bars`）；只有一個數（`number`） |
| 兩三個數比高低，"差一大截" | `bars` | 超過 5 根（`ranking`）；差距小到看不出來（別比） |
| 兩樣本該相配的東西差得離譜（估值 vs 收入） | `versus` | 差別不大（別比）；要讀出具體差多少（`bars`） |
| 一串數按年變化、按年累計 | `chart` | 只有一個數（`number`）；兩三個數比大小（`bars`） |
| 整體裡的一部分（佔比、份額） | `share` | 超過 5 塊（合成"其他"）；比幾個整體的大小（`versus`） |
| 五家以上排個隊 | `ranking` | 只有兩三家（`bars` / `versus`） |
| 甲 vs 乙逐項比（兩到四項） | `compare` | 超過 4 行（挑最要緊的）；只比一項（`versus` / `bars`） |

**關係和結構**

| 這句話在說什麼 | 用 | 什麼時候別用（換成） |
|---|---|---|
| 幾家公司 / 幾個人並列；誰收購誰（巢狀）、誰出局（變灰） | `discs` | 它們之間有流向（`network`）；只有一家（`number` / `footage`） |
| 錢 / 關係怎麼流：誰投了誰、錢轉了一圈 | `network` | 沒有方向的並列（`discs`） |
| 一件事分幾步、幾個條件成不成立 | `flow` | 只是並列幾樣（`discs`）；按時間先後（`timeline`） |
| 三到六件事按時間排 | `timeline` | 只有兩個時間點（`change` / `bars`） |
| 國家、城市之間的事（在哪設計、在哪造、錢流向哪） | `map` | 要精確國界（`board` + 標準地圖底圖放進 `under`）；只是"這家公司在美國"（一句話帶過） |
| 一群裡拎出一個（"各國都在砸錢，最大的是美國"） | `cards3d` | 只有兩三樣（`discs`）；不用拎主角（`discs` 一排） |
| 幾樣東西要放在一個世界裡講，上面幾個都對不上 | `board` | 只有一個數（`number`）；要看清一段實拍（`footage`） |

**人**

| 這句話在說什麼 | 用 | 什麼時候別用（換成） |
|---|---|---|
| 這個人 = 這個數 / 這個身份（第一次把人和數綁在一起） | `person` | 沒有他的摳像（`profile` 用 `photo`，或 `discs` 的照片圓盤）；巨字超過兩組、每組超過 4 個字 |
| 關鍵人物第一次出場：是誰、什麼身份、兩三件事 | `profile` | 只出現一次、不重要（一句話帶過）；已經出場過（`discs` 的照片圓盤或 `person`） |
| 當事人的一句原話，沒有能用的原聲畫面 | `quote` | 有原聲畫面（`footage` 放原聲，前一句做鋪墊）；話超過 30 字 |

**真畫面和證據**

| 這句話在說什麼 | 用 | 什麼時候別用（換成） |
|---|---|---|
| 說到的東西有真畫面：人、地方、產品、釋出會 | `footage` | 認不出是誰、是什麼（換一段有臉、logo、標題的）；想在上面加字（`person` / `montage`） |
| 這件事 = 這些畫面（前景釘一個數或標題） | `montage` | 前景沒有視線落點；底下的實拍要看清（`footage`） |
| 兩三樣有畫面的東西並列（晶片和資料中心） | `frames` | 只有一樣（`footage`）；超過 3 樣 |
| 觀眾可能不信的數：給原文出處 | `article` | 原文要讀很久（壓成一句再刷）；沒核實過的數（別放）；好幾篇要一起看（`desk`） |
| 幾家各自的新聞（截圖示題裡有公司名和金額） | `desk` | 截圖的字太小、認不出是哪家（換截圖，或 `discs`）；只有一篇（`article`） |
| 從上一鏡拎出一份證據 / 一句原聲，看完回來 | `popup` | 在 board 系列裡（用 `pop` 步驟，舞臺不凍住）；證據要細讀（`article` / `footage`）；第一鏡 |
| 說法很多，最要緊的只有一句 | `headlines` | 編不出真的標題；只有兩三條（`desk` 放真截圖） |
| 一個 App / 網站 / AI 產品的介面 | `device` | 截圖上沒有要看的東西（`footage` 放錄屏）；有官方產品實拍（`footage`） |

**結構和包裝**

| 這句話在說什麼 | 用 | 什麼時候別用（換成） |
|---|---|---|
| 片名 / 章節：這支片（這一段）要回答什麼問題 | `title` | 片名前空等（第一句說完就進）；章節卡超過 3 張 |
| 長片的目錄、現在講到第幾章 | `agenda` | 一兩分鐘的短片（不用目錄） |
| 一句判斷壓成金句：結尾，或者一大段講完收一句 | `statement` | 放一段話（只放一兩行）；一支片超過 3 次 |
| 開頭鉤子：全網都在說一個詞 | `flash` | 話題不熱、編不出真的出處；關鍵詞超過 4 個字；不是開頭 |
| 上面都對不上 | `custom` | 只是想換個花樣（先找最對得上的那個） |
