# 風格語言

前半是從三條同類參考片量出來的，後半是示例片《AI到底有多燒錢》裡證明成立的具體做法。數值是起點，不是規定。新片按自己的內容調，但要保持“同一個世界”：深色織物舞臺、每一段一種品牌色光、奶油金的大數字、厚玻璃圓盤、白底圖表、當事人的摳像、實拍乾淨地全屏或者裝進白邊畫框。

## 參考片本身（量出來的）

- **一個問題撐起全片**：開頭 5–7 秒丟出極值或反差，結尾回答它，並壓成一句判斷。
- **圖形有解釋任務，並且在同一段裡不斷累積**：多個物件比大小，就用同一個座標系；關係複雜，就複用節點、補箭頭；證據多，就放原文並推近。
- **人和圖形一起動**是它最招牌的東西：人身後換背景、人站在巨字前面、卡片在人旁邊冒出來、圓盤環繞著人、人在兩件物體中間的窗裡。沒有主持人時，就用當事人的實拍摳像來演。
- **實拍以直接切為主**，蒙太奇裡大約一秒一鏡，但每一鏡都是這句話裡說到的東西，而且同屬一件事。前景釘著標題或圓盤時，底下的實拍可以 0.5 秒一換。
- **新聞和報告**：先給整頁認出處，再推近到那一句，加高亮或中文；無關的字壓淡。
- **人物第一次出場**配照片和名牌，後面可以縮成圓形頭像。
- **反應梗**是獨立的短插入：上一畫面壓暗，中間開一個小窗，梗過去馬上回到講解。
- **字幕**是穩定的跟讀層：白色、底部居中一行、整句短語直接替換，不逐字打出。強調的內容另開一層，不擠進字幕。
- **運動**：東西出現很樸素，大運動交給鏡頭；B-roll 約 2 秒換一個畫面，幾乎不定住；細節和數字見 `motion.md`。

## 在本片裡成立的具體做法

**畫面基礎**：1920×1080。圖形段的底是一片抽象舞臺，不假裝是真實場景：
- 深藍織物紋理（`stage_navy.jpg`，生成的中性紋理），亮度 1.45、飽和 0.72，四周壓暗；
- 講到某一家時，換成這家的顏色光：紋理去色後用濾色疊加約 0.42，再疊一團品牌色的徑向光（英偉達 `#3b7a1c`、OpenAI `#1c6b62`、虧損 `#6e1f26`），四周壓到黑。
- 全片疊一層很淡的顆粒。

**字幕**：MiSans Medium 500，60px，白色，陰影 `0 2px 6px #000b, 0 0 18px #0007`，字幕盒子頂在 y=936（字身約 48px 高，上沿 y≈954、下沿 y≈1002；`starter/film.css` 就是這套）。英文和數字用 Montserrat 斜體（原版用的 Century Gothic Italic 是系統字型、不能隨 skill 帶走，換成了這個），這樣中文裡夾的英文不會顯得突兀。超過 20 個字就按逗號拆成短語，卡著字的時刻替換。

**大數字**：Bebas Neue（Num），約 240–320px，從上到下是奶油金漸變 `#fffef2 → #fff3b5 → #efdc7a`，外發光很淡。`$` 縮到 0.42 倍、垂直居中；單位“億/萬億”用阿里媽媽數黑體，0.3 倍大，顏色 `#f2e27e`。滾動的數寫滿位（`$725,000,000,000`），等寬數字，按十億取整。

**巨字**（人站在它前面）：數字 Bebas，漢字阿里媽媽數黑體（0.6 倍）。
- 字號約 470–520px，漸變從白到這一段的色，比如英偉達 `#fff → #cfe6b0`、OpenAI `#e6f6f2 → #86c4b6`、第一名的金 `#fffaf0 → #e8cf86`；
- 漸變裡用 soft-light 壓一層顆粒（印刷質感），背後投一層深影；
- 分兩組放在人頭的兩側（`5.2` | `萬億`、`全球` | `第一`），字的上沿高過頭頂一點，手臂可以壓到字的下半截；
- 出現時 0.3 秒從 1.12 倍長到 1。

**眉題**：數黑體 44px，字間距 10px，`#f1ead2`；下面可以有一行 Montserrat 600、17px、字間距 7px 的英文（`NVIDIA · MARKET CAP`），透明度 0.55。一幀最多一組。

**當事人摳像**：
- 實拍逐幀摳（`scripts/matte.py` + `matte_clean.py`），按每幀頭肩中心釘在構圖位置；
- 放大約 1.15–1.2 倍，下半身出畫；
- 身後一團同色的光（`halo`，半徑約 550、不透明度 0.2，濾色疊加），讓人落在這個底上；
- 對比度 1.04、飽和 0.96，和底同一個調子。

**厚玻璃圓盤**（實體節點）：一家公司一個盤，全片複用。
- 盤的組成：品牌色徑向漸變，加一圈邊緣高光、厚度和投影；白色 logo、中文名（數黑體）、上下各一條細裝飾線；盤的右側是當事人的摳像。
- 調色盤：谷歌和 Meta 用藍、微軟用鋼藍、亞馬遜用琥珀、英偉達用綠、OpenAI 用青綠、甲骨文用磚紅。
- 放到 3D 桌面上時，離鏡頭對著的點越遠越虛（最多約 5px）；不是此刻在講的盤，壓暗到 0.4 並去飽和。

**價籤和小卡**：
- 價籤（盤下面的數）是深色小牌，金色細邊框，Bebas 數字，上面一行中文小字說明這是什麼（“估值”）。
- 人旁邊冒出來的小卡是磨砂玻璃（白色 15% 漸變、1.5px 白邊、背景模糊 14px），上面一行數黑體 30px，下面 Bebas 120px 的數。

**白底圖表**：白色圓角卡片，略帶透視，虛線網格，虧損曲線用紅色並在下方鋪淺紅面積，標題用數黑體中文。累計數跟著曲線滾，放在曲線讓出來的那塊空白裡（虧損曲線往右下走，就放右上），紅色 Bebas。

**片名**：金屬質感的數黑體（chrome），約 168px，上方的眉題就是剛數出來的那個數，下方一行英文（Montserrat 22px、字間距 12px、透明度 0.48）。底下是這支片自己的實拍（資料中心、工地），壓暗到 0.36、去色到 0.5、略虛，0.42 秒一換。

**實拍**：
- 一鏡只講一個物件時，全屏。
- 兩樣東西並列（比如“晶片和資料中心”）時，裝進白邊畫框：6px `#f4f1ea` 邊、12px 圓角、深投影，框上方用數黑體寫中文標籤。畫框甩進來時帶方向模糊。
- 當底用（字是主角）時壓暗、去色、略虛。
- 裁掉原片燒進去的字幕和臺標（抽幀時放大裁切，`footage.py extract` 的 zoom/ax/ay）。

**新聞原文**：白底頁面。整頁鏡頭縮放約 1.2–1.25 倍並慢推，接著硬切到 1.75–2.6 倍的特寫。熒光筆用 `#ffd84a` 正片疊底，0.4 秒刷過。特寫時疊一層白色徑向霧，把無關文字壓淡。要它退成底時，整頁倒成透視桌面（約 62°）、壓暗到 0.28。

**反應窗**：背景亮度降到 0.32，模糊 5px；視窗 1120×630，位置 (400,150)，圓角 10，深投影；從那個人的圓盤的位置撐開（位置要在渲出來的幀上實測）。

**不要用**：
- 站酷慶科黃油體，它會把“多”“市”這類字畫壞；
- AI 生成的電影感氛圍背景（熔爐、賭場、晶片神殿）；
- 賭場航拍這種太直白的比喻鏡頭；
- 清楚的實拍上貼名牌框；
- 左上角常駐的章節牌、角落的來源小字。
