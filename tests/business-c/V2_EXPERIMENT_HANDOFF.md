## 必須保持的財務與故事界線

- 一百萬元是**假設已接到的合約金額**，不是簽約時已認列營收，也不是銀行現金。
- 材料 45 萬、薪資及廠房費 25 萬，共 70 萬，須在收款前支付；假設可動用現金 20 萬，缺口 50 萬。
- 假設客戶在**完成交貨驗收後 90 天**支付，而非簽約後 90 天。
- 現金缺口是流動性風險，不等於公司已經倒閉，更不代表一定破產。
- 虛構人物的對白不是目鏡大叔本人、真實店家或真實員工的錄音／發言。

## V2 验收 Gate

| 項目 | 可視為通過的條件 |
|---|---|
| 財務 | `1000000` 是訂單；`450000 + 250000 - 200000 = 500000` |
| 人物 | 兩個不同虛構角色、未冒用目鏡大叔或真實客戶的相貌 |
| 金流 | 真正可見的流出運動，非單純 70／20／50 三張靜態卡 |
| 成片 | V2 MP4 能被 FFprobe 證實為 720×1280 H.264 30fps，長度約 53.23 秒 |
| 音訊 | 在 Fish 進入影片前僅可標 `VISUAL_ONLY`；有聲驗收必須有 AAC + 已校對的 timing |
| 流程 | 所有發布或部署行為禁止；不合併 main，不修改正式 MCP |
